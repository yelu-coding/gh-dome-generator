# 🌀 GH Dome Generator  
**Parametric Design of the Reichstag Dome**  
Grasshopper & Python · Visual Programming Advanced · RWTH Aachen

This repository showcases the parametric modeling and scripting of the Reichstag Dome.  
The project explores geometric logic, point cloud scripting, and digital fabrication readiness  
via Rhino + Grasshopper and GHPython components.

This project was created during the **Visual Programming Advanced** course at RWTH Aachen.

---

## 🌍 Description | 多语言简介 | Projektbeschreibung

### 🇬🇧 English  
This project develops a parametric model of the Reichstag Dome (Berlin, Norman Foster) using Grasshopper and Python.  
It demonstrates rule-based geometry, point cloud generation, structural logic, and 2D fabrication output.

Key components include:
- Scripting of conical, cylindrical, spherical, and catenary domes
- Interior elements: spiraling ramps, mirrored inner cone, visitor platforms
- Structural systems: vertical girders, horizontal beams, roof system
- Façade logic & glass split patterns
- 2D unfolding of mirrored cone for fabrication

### 🇨🇳 中文  
本项目使用 Grasshopper 和 Python 构建柏林联邦议会穹顶（Reichstag Dome）的参数化模型，  
通过点云生成、几何规则、构造逻辑与制造展开等方式，探索自动化建模流程。

## 🧠 Project Goals

- ✅ Generate geometric variants of the Reichstag Dome using mathematical rules  
- ✅ Script parametric point clouds for dome shells in Python  
- ✅ Assemble structural & interior systems via modular GH components  
- ✅ Produce fabrication-ready 2D drawings from 3D model  
- ✅ Explore scalability by adjusting core parameters
